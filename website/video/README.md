# Видеообзор Femboy Launcher

25 секунд, 1920×1080, 24 кадра/с, без звука. Это монтаж настоящих скриншотов из демонстрационной галереи сайта,
а не запись установки модов или запуска игры. Звуковая дорожка не используется.

Монтаж: `src/Composition.tsx`, регистрация: `src/Root.tsx`. Шрифты и логотип те же, что на сайте.
Пять сцен: сборки (0–5 с), Modrinth (5–11 с), проверка (11–16 с), темы (16–21 с), приглашение скачать (21–25 с).

Из папки `website/video`:

```
npm install           # зависимости только видеопроекта
npm run dev           # скопировать актуальные исходные изображения и открыть Remotion Studio
npm run lint          # ESLint и TypeScript
npm run render:site   # обновить MP4 и обложку в ../public/media/
```

`scripts/prepare-assets.mjs` копирует исходные изображения из соседнего сайта в `video/public`.
Исходники лаунчера, профили, аккаунты и настоящие пользовательские данные для этого не нужны.
Файлы шрифтов сопровождаются лицензией в `public/fonts/LICENSE-fonts.txt`.

После изменения содержания ролика обнови также `../src/components/Overview.astro` и `../public/media/launcher-overview.ru.vtt`,
затем собери сайт обычным `npm run build` из `website` и опубликуй его в Firebase.
Обычная сборка сайта использует готовые медиафайлы и не запускает Remotion. В Firebase отправляется только `website/dist`.
